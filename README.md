**Quais serão as principais funcionalidades?**

- [Funcionalidade 1: Enviar notificações para o usuário.]
- [Funcionalidade 2: Analisar a rotina do usuário.]

## 🛠️ Tecnologias utilizadas

**Quais tecnologias você pretende utilizar e por quê?**

- **Python:** linguagem principal do projeto. É simples de ler, tem muitas bibliotecas prontas e é ótima para cálculos e automação.
- **Bibliotecas:**
  - `datetime`: controlar horários das notificações e a rotina do usuário.
  - `random`: sortear missões e dicas diferentes a cada dia.
  - `json` ou `sqlite3`: guardar os dados da rotina, o nível e as missões concluídas.
  - `plyer`: enviar notificações para o usuário.
  - `discord.py` (opcional): enviar as sugestões por chat, como uma conversa com o "agente".
- **Frameworks:** Streamlit (ou Flask) para criar a interface do app de forma rápida, com formulários para a rotina e a tela de missões e nível.
- **APIs ou banco de dados:**
  - API de IA (como a do Claude) para interpretar a rotina e escolher as ações mais adequadas.
  - API Open-Meteo (gratuita) para consultar o clima, por exemplo sugerir reaproveitar água da chuva em dias chuvosos.
  - Banco de dados SQLite para guardar o perfil e o progresso de cada usuário.
